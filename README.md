# PokéTerminal (Pokéthon)
Pokémon In Your Terminal like its Nethack (or any other terminal rpg)!

## Mandatory Disclaimer
If you want to update this game at this point, please delete your old files, don't worry, there is zero resemblence of progress at least for now, since this game is heavily unfinished, and is mostly just a proof of concept than anything else. Expect heavy changes throughout updates.

- Website: https://nigelisguy.github.io/pokethon/web/index.html
- Go to releases, click download for your system
- Run pokethon/main.py in a terminal

## Modding
- Go to devtools, and open any of the tools needed, should be pretty self explanatory, but do note that SOME OF THESE TOOLS ARE UNFINISHED, AND MIGHT HAVE COMPLETE UI OVERHAULS, as well as the fact they are pretty buggy
- A guide will be released soon
